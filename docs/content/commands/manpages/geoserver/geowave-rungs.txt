[[gs-run-name]]
==== NAME

geowave-gs-run - Runs a standalone GeoServer instance

[[gs-run-synopsis]]
==== SYNOPSIS

  geowave gs run [options]

[[gs-run-description]]
==== DESCRIPTION

This command runs a standalone GeoServer instance, for local evaluation, testing and debugging, with the GeoWave plugin on its classpath.  It needs GeoServer's web application: unpack the GeoServer ${geoserver.version} web archive (WAR) into a directory and pass that directory with `--directory`.  The WAR is published at `https://repo.osgeo.org/repository/release/org/geoserver/web/gs-web-app/${geoserver.version}/gs-web-app-${geoserver.version}.war`.

Use GeoServer ${geoserver.version}, the version GeoWave is built against.  GeoServer runs on Jetty 12.1 (Jakarta Servlet 6.1), and the command adds the tools JAR to the web application's classpath after the WAR's own `WEB-INF/lib`, where an installed plugin would be: GeoServer runs on the libraries it ships with, and takes GeoWave's classes, and anything else it does not have, from the tools JAR.

[WARNING]
====
This command is for local evaluation only.  GeoServer starts with its default administrator account (user `admin`, password `geoserver`) and a configuration that has not been secured.  The command listens on 127.0.0.1 by default, and it must not be exposed to untrusted networks or used as a deployment; for that, install the GeoWave GeoServer plugin in a GeoServer that is kept up to date with its security releases.
====

[[gs-run-options]]
==== OPTIONS

*-d, --directory* _<path>_::
  The directory containing the unpacked GeoServer WAR. Default is `lib/services/third-party/embedded-geoserver/geoserver` under `~/geowave`, or under the directory in the `geowave.home` system property if it is set.
  
*--host* _<host>_::
  The host name or IP address for GeoServer to listen on.  Default is `127.0.0.1`, which only this machine can reach.  Listening on another interface makes GeoServer reachable from other machines on that network; see the warning above.

*-i, --interactive*::
  If specified, prompt for user input to end the process.
  
*-p, --port* _<port>_::
  Select the port for GeoServer to listen on.  Default is 8080.

[[gs-run-examples]]
==== EXAMPLES

Run the GeoServer WAR unpacked in the `geoserver` directory:

  geowave gs run -d geoserver

Run it on port 8000 instead of 8080:

  geowave gs run -d geoserver -p 8000
